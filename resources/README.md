# Project Resources & Reference Links

This directory organizes learning materials, documentation links, and project references for the Peer Sync platform.

## Resource Guidelines
- **No Large Files:** Do not commit large binary downloads (such as video recordings, large datasets, or heavy PDF bundles) to this Git repository.
- **Link Over Files:** Store large files on shared university cloud storage (e.g., Google Drive, OneDrive) and provide reference links below.
